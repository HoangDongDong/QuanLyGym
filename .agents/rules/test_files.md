# Quy định về file test và file tạm

- Tất cả các file test, script chạy thử nghiệm (scratch scripts), dữ liệu mẫu thử nghiệm phải được lưu trong thư mục `scratch/` (`d:/QuanLyPhongGym/scratch/`).
- Tuyệt đối không tạo các file test tạm thời ở thư mục gốc dự án.
- Giữ gìn sự sạch sẽ cho cấu trúc thư mục chính của dự án.
